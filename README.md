## Featured Project

### High-Throughput Log Ingestion & Query Service

> Foothill Technology Solutions Internship Final Project

A performance-oriented backend system for ingesting, storing, querying, aggregating, and retaining large volumes of structured logs.

**Tech:** .NET 10 · ASP.NET Core · PostgreSQL 17 · Docker · Testcontainers · xUnit · k6 · Prometheus

#### Highlights

- Designed using **Clean Architecture** with clear separation between application, domain, infrastructure, and API concerns
- Implemented batch ingestion with **per-entry validation**
- Built combinable filtering by service, level, time range, attributes, and message content
- Implemented **cursor-based / keyset pagination**
- Added time-bucketed aggregations and grouped queries
- Designed partition-based log retention
- Built a bounded producer-consumer ingestion pipeline
- Used PostgreSQL **binary COPY** and approximately **5,000-row group commits**
- Added pre-aggregated minute rollups for fast analytical queries
- Added **100 automated tests** using xUnit and Testcontainers
- Integrated CI contract validation and Prometheus metrics

#### Performance

Under the required application limits of:

- **0.5 CPU**
- **256 MB RAM**

the system achieved approximately:

- **14,999 logs/second ingestion throughput**
- **~2 ms p95 aggregation latency**
- **96.7 / 100** on Foothill Technology Solutions' standardized final-project benchmark

➡️ **Repository:** [log-service](https://github.com/ahmad1542/log-service)
